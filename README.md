## 🚀 תוסף Stips Download (גרסה 1.0.0)

תוסף Chrome/Chromium להורדת שיחות מלאות מסטיפס:
- **זיהוי צ'אט אוטומטי**: מזהה עמודי שיחה (`/messages/<ID>`) וקישורים ומזריק כפתור הורדה דיסקרטי.
- **הורדה ישירה דרך ה-API**: משיכת היסטוריה מלאה ללא תלות בגלילת מסך פיזית.
- **עמידות גבוהה (Checkpoint & Resume)**: שמירה אוטומטית ב-IndexedDB בכל אצווה והתמודדות עם ניתוקי רשת.
- **ארכיון HTML עצמאי (Offline Single File)**: קובץ יחיד, נטול תלויות חיצוניות, עם וירטואליזציה מלאה (חלקה גם עבור 20,000+ הודעות).
- **תאריכים מלאים**: תאריכים לועזיים ועבריים באותיות (כגון: `י"ב באדר תשפ"ו`).
- **לוח שנה אינטראקטיבי וחיפוש סופר-מהיר**: קפיצה לפי ימים וחיפוש בזיכרון עם סובלנות לשגיאות הקלדה.
- **ייצוא**: תמיכה מלאה ב-HTML, JSON, ו-TXT.

### התקנה מקומית למפתחים:
1. פתחו את הדפדפן (Chrome / Edge / Brave).
2. היכנסו לכתובת: `chrome://extensions/`.
3. הפעילו **Developer mode** (מצב מפתח) בפינה העליונה.
4. לחצו על **Load unpacked** (טעינת תוסף לא ארוז).
5. בחרו בתיקייה:
   `stips-tools/extensions/stips-download` (או `Documents/Stips Download`).

- **סמל ייעודי בפינה הימנית-תחתונה** (באדום `#C9372F`):
  - **Stips Notifier**: בועת שיחה אדומה 💬
  - **Stips Reveal**: זכוכית מגדלת אדומה 🔍
  - **Stips Download**: חץ הנכנס למגש הורדה 📥
