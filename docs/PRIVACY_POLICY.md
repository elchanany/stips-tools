# Privacy Policy - Stips Tools Suite

All tools and browser extensions within the **stips-tools** repository are built on a strict **Zero-Telemetry, Client-First** philosophy:

1. **No External Transmission**:
   Neither message content, user credentials, browsing history, nor tokens are transmitted to any third-party server or developer endpoints.
2. **Local Processing**:
   All processing, storage (IndexedDB, localStorage), and file generation (HTML, JSON, TXT) take place 100% locally within the user's browser.
3. **Official Stips API Only**:
   Network calls are made exclusively to `https://stips.co.il` endpoints using the user's existing authenticated browser session to execute user-requested actions.
