תיאור מפורט לחנות (Store Description):
--------------------------------------------------------------------------------
Stips Download - הורדת שיחות סטיפס לארכיון מקומי, עשיר, נוח לחיפוש ומוכן ל-AI!

רוצים לגבות שיחה חשובה מסטיפס? צריכים למצוא הודעה שנשלחה לפני שנתיים? רוצים לנתח שיחה ארוכה בעזרת בינה מלאכותית?
עם "Stips Download" תוכלו להוריד ולשמור את כל היסטוריית השיחות שלכם בסטיפס בקליק אחד, לצפות בהן בכל זמן ללא צורך באינטרנט, או להעלות אותן ל-AI!

🌟 התכונות המרכזיות:

• זיהוי שיחה אוטומטי:
  גולשים בסטיפס? התוסף מזהה אוטומטית עמודי שיחה או רשימת מסרים ומציג כפתור הורדה אלגנטי ומותאם בצבעי האתר ישירות ליד כותרת השיחה.

• הורדה מהירה ושלמה בלחיצה אחת:
  ללא צורך בגלילה ידנית מייגעת לאחור! התוסף מוריד את היסטוריית השיחה המלאה בצורה חלקה, עמידה ומסודרת ישירות מתוך הדפדפן שלכם.

• מוכן ל-AI (ChatGPT, Claude ועוד):
  התוסף מאפשר ייצוא לקובץ טקסט נקי (TXT) או קובץ נתונים (JSON). תוכלו להעלות את קובץ השיחה ישירות ל-ChatGPT או לכל כלי AI אחר כדי:
  - לקבל סיכום תמציתי ומדויק של שיחות ארוכות.
  - לשאול שאלות על נושאים שדיברתם עליהם בעבר ("מתי דיברנו על...", "איזה סרט המלצת לי?").
  - לנתח דפוסי שיחה ולמצוא תובנות בצורה קלה ומהירה!

• עמידות מלאה לניתוקים (Checkpoint & Resume):
  השיחה שלכם כוללת עשרות אלפי הודעות והאינטרנט התנתק? אין בעיה! התוסף שומר את ההתקדמות מקומית וממשיך בדיוק מהנקודה שבה עצרתם.

• ארכיון HTML עצמאי ומהיר (Offline Single File):
  השיחה מיוצאת לקובץ HTML עצמאי ויפהפה הפועל ישירות במחשב ללא שום תלות בשרת, ללא ספריות חיצוניות וללא צורך ברשת.
  הארכיון כולל מצב כהה/בהיר, וירטואליזציה (מציג בצורה חלקה גם שיחות של מעל 20,000 הודעות!), ומפרידי תאריכים אלגנטיים.

• תאריכים עבריים ולועזיים מלאים:
  כולל יום, חודש, שנה, שעה מדויקת, ותאריך עברי מלא באותיות (כגון: י"ב באדר תשפ"ו).

• לוח שנה אינטראקטיבי:
  קפיצה ישירה להודעות לפי תאריכים נבחרים (בלוח לועזי או עברי). רק ימים שבהם נשלחו הודעות מודגשים וזמינים לקליק.

• חיפוש סופר-מהיר בזיכרון (In-Memory Search):
  מנוע חיפוש מתקדם שמאתר מילים, ביטויים, ואף מתמודד עם שגיאות הקלדה קלות (Fuzzy Typo Tolerance). לחיצה על תוצאה מקפיצה ישירות להודעה המבוקשת.

• יצוא במגוון פורמטים לבחירתכם:
  ייצאו את השיחה בקלות כקובץ HTML עשיר לעיון עצמאי, קובץ JSON מובנה, או קובץ TXT קריא המותאם להזנה למודלי בינה מלאכותית.

🔒 פרטיות מעל הכל:
כל הנתונים נשמרים ומעובדים אך ורק במחשב האישי שלכם בדפדפן! התוסף אינו שולח שום מידע, הודעה או פרט מזהה לשרת חיצוני כלשהו.

הצהרות פרטיות והצדקת הרשאות (Privacy & Permissions Justification):
--------------------------------------------------------------------------------

Single Purpose:
"To allow users of stips.co.il to download, backup, and view their personal chat message history locally in a self-contained offline archive."

Permission Justification:
1. storage:
   "Used to save user preferences, theme selection (dark/light), and local download checkpoint jobs in IndexedDB so large chat history downloads can be resumed if disconnected."

2. downloads:
   "Used to save the generated offline HTML archive, JSON, or TXT file directly to the user's local downloads folder upon clicking export."

3. scripting:
   "Used to trigger the download flow on the active Stips tab when initiated from the extension action popup."

Host Permissions (https://stips.co.il/*):
   "Required to detect chat conversation pages on stips.co.il and allow authenticated users to export their own chat history directly to local files."

Data Usage:
- No data is collected or transmitted outside the user's browser.
- No remote analytics or third-party servers.
- All storage is strictly client-side.
